Proposes a distributed flocking control algorithm for multi-agent systems using a leader-follower architecture. Each agent uses a consensus protocol to estimate the flocking center, enabling decentralized formation control without explicit inter-agent distance measurements. Presented at IECON 2016, with 18+ citations.

Proposes a fully decentralized machine learning framework that uses the Hashgraph consensus protocol to coordinate model updates among distributed agents. Hashgraph's asynchronous Byzantine fault-tolerant consensus eliminates the need for a trusted central server while providing strong consistency and ordering guarantees. Presented at IEEE COMPSAC 2025.
